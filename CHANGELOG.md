- A signed-in member can submit, edit, or withdraw a tool review only while `userRatingsEnabled()` is true. The write checks a verified email, the 72-hour wait, staff and banned accounts, and every verified email against the tool’s vendor domains. It stores `ip_hmac`, `net_hmac`, and `ip_key_id` from `K_ip` and `K_net`. A missing IP, a missing review HMAC key, or a limiter error or timeout returns `unavailable` and writes no review. A full window returns `rate_limited`. A refused display name returns `name_blocked`. The stored name is the raw snapshot. Its length is counted in Unicode code points, and the NFKC form is capped at 64 code points because that form can expand about 18 times. The `reviews.display_name` check is still 60 characters, so a raw name of 61 to 64 code points is refused without a migration. A disclosed connection sets `counts_toward_score` to 0. Link signals are an audit note only. Each change writes one `moderation_events` row and recomputes `review_aggregates` in the same transaction. Delete revalidates `reviews:<slug>` and `/tools/<slug>` after commit. The user id comes from the caller, never the form.
