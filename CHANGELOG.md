- A path with a malformed percent-escape, such as `/%E0%A4%A` or `/admin/%E0%A4%A`, returns plain text 400 with `Cache-Control: no-store` and `X-Robots-Tag: noindex, nofollow`. Next decodes `/:path*` header params before the proxy runs, and that throw was a 500. The proxy rejects the raw path when it runs. `scripts/serve.ts` and a `vercel.json` route reject it before Next decodes. A valid encoding such as `/tools/%63hatgpt` still reaches that tool page.

- Review IP HMAC secrets are checked by one validator at build and at server boot. `REVIEW_IP_HMAC_SECRET` is required when `VERCEL_ENV=production` and when `USER_RATINGS=on`, must be at least 32 bytes, and has no fallback key. `REVIEW_IP_HMAC_KEY_ID` is required with it and must match `^k[1-9][0-9]{0,3}$`. An optional `REVIEW_IP_HMAC_SECRET_PREVIOUS` must be at least 32 bytes and needs `REVIEW_IP_HMAC_KEY_ID_PREVIOUS` in that format and different from the current id. A previous id without a previous secret is refused. The review secret must not equal `RATE_LIMIT_HMAC_SECRET` or the previous review secret; the check compares SHA-256 digests with `timingSafeEqual`. `RATE_LIMIT_HMAC_SECRET` must be at least 32 bytes in production. Preview still uses the HKDF fallback when that secret is unset. `K_ip` and `K_net` derive HKDF-SHA256 subkeys (`bestbotfor/review-ip/v1`, `bestbotfor/review-net/v1`) for a later review writer. `BBF_E2E_HOOKS=1` fails the build when `VERCEL=1` or `VERCEL_ENV=production`. `NODE_ENV=production` does not refuse the hooks, because `next build` always sets it. Key ids are matched exactly, so leading or trailing whitespace is refused. Errors name the variable and the rule only.
- `/logos/*` sends `Cache-Control: public, max-age=31536000, immutable`.
- A `RATE_LIMIT_HMAC_SECRET` shorter than 16 characters is not used as the HMAC key. The process derives a 32-byte key with HKDF-SHA256 from another server secret of at least 16 characters, and logs a warning that names the source variable. When no candidate is long enough, it keeps one process-local key and warns about that instead. The secret and the derived key are not logged.
